# RAM Optimizer — سرویس ویندوز آزادسازی خودکار حافظه

یک سرویس ویندوز نوشته‌شده با پایتون که **بدون هیچ رابط کاربری یا تنظیماتی** در
پس‌زمینه کار می‌کند و همیشه حواسش به RAM سیستم است:

- هر **۶۰ ثانیه** میزان مصرف رم را بررسی می‌کند.
- اگر مصرف به **۷۵٪** یا بیشتر رسید، دو کار انجام می‌دهد:
  1. **`EmptyWorkingSet`** روی همه‌ی پروسه‌ها → رمی که برنامه‌ها گرفته‌اند ولی
     دیگر استفاده نمی‌کنند آزاد می‌شود (دقیقاً کار برنامه‌های RAM Optimizer).
  2. **خالی کردن Standby List** → معادل گزینه‌ی «Empty Standby List» در ابزار
     رسمی RAMMap مایکروسافت؛ حافظه‌ی کش هم واقعاً آزاد می‌شود.

فایل گزارش: `C:\ProgramData\RamOptimizer\ram_optimizer.log`
گزارش خطاهای بحرانی: `C:\ProgramData\RamOptimizer\crash.log`

> **نکته‌ی صادقانه:** ویندوز جدید خودش حافظه را خوب مدیریت می‌کند و «رم خالی زیاد»
> به‌خودیِ خود باعث سرعت بیشتر نمی‌شود. با این حال روی سیستم‌هایی با رم کم یا
> برنامه‌هایی که حافظه را نگه می‌دارند و پس نمی‌دهند، این ابزار به‌طور محسوس کمک
> می‌کند.

---

## فایل‌های این پروژه

| فایل | کاربرد |
|---|---|
| `ram_optimizer.py` | هسته‌ی برنامه (منطق آزادسازی رم) — مستقل هم قابل اجراست |
| `ram_optimizer_service.py` | سرویس ویندوز که از هسته استفاده می‌کند |
| `requirements.txt` | کتابخانه‌های موردنیاز (psutil، pywin32، pyinstaller) |
| `build_exe.bat` | ساخت خودکار exe (حالت onedir — مناسب سرویس ویندوز) |
| `install_service.bat` / `uninstall_service.bat` | نصب / حذف سرویس ویندوز |
| `install_task.bat` / `uninstall_task.bat` | راه‌جایگزین: اجرا با Task Scheduler |

## راه‌اندازی (روش اصلی — ساخت exe و نصب سرویس)

### پیش‌نیاز
1. ویندوز ۱۰ یا ۱۱ (۶۴ بیتی)
2. نصب **Python 3.8 یا جدیدتر** از [python.org](https://www.python.org/downloads/)
   — حین نصب تیک **«Add python.exe to PATH»** را بزنید.

### قدم‌ها
1. **`build_exe.bat`** را دابل‌کلیک کنید و صبر کنید تا تمام شود.
2. وارد پوشه‌ی **`release`** شوید و **`install_service.bat`** را دابل‌کلیک کنید
   (در پنجره‌ی UAC گزینه‌ی Yes را بزنید).
3. تمام! ✅ سرویس نصب و اجرا شد و با هر بار روشن شدن ویندوز خودکار کار می‌کند.

⚠️ **مهم:** پوشه‌ی `RamOptimizerService` (که کنار bat های نصب قرار دارد) را جابه‌جا
یا حذف نکنید؛ exe از داخل همان پوشه اجرا می‌شود. اگر خواستید جای برنامه را عوض
کنید، اول `uninstall_service.bat` را اجرا کنید، پوشه را جابه‌جا کنید و دوباره نصب کنید.

### حذف کامل
**`uninstall_service.bat`** را دابل‌کلیک کنید.

## رفع خطای «The service did not respond to the start or control request in a timely fashion»

این خطا یعنی مدیر سرویس ویندوز نتوانسته ظرف ۳۰ ثانیه به برنامه وصل شود. نسخه‌ی
فعلی پروژه برای رفع همین مشکل اصلاح شده (گزارش فوری وضعیت `SERVICE_RUNNING` به
ویندوز + بیلد onedir به‌جای onefile). قدم‌ها:

1. با فایل **`uninstall_service.bat`** نسخه‌ی قبلی را کامل حذف کنید.
2. با **`build_exe.bat`** دوباره بسازید و با **`install_service.bat`** نصب کنید.
3. اگر باز هم استارت نشد، فایل‌های زیر را بررسی کنید:
   - `C:\ProgramData\RamOptimizer\crash.log`
   - `C:\ProgramData\RamOptimizer\ram_optimizer.log`
4. برای دیدن خطای دقیق، در یک **CMD با دسترسی ادمین** این دستور را اجرا کنید —
   سرویس در حالت عیب‌یابی داخل کنسول اجرا می‌شود و هر خطایی را مستقیم نشان می‌دهد
   (توقف با `Ctrl+C`):

   ```bat
   cd /d "مسیر\release\RamOptimizerService"
   RamOptimizerService.exe debug
   ```

5. گاهی آنتی‌ویروس اجرای سرویس را کند یا بلاک می‌کند — پوشه‌ی `release` را به
   Exclusion List آنتی‌ویروس اضافه کنید و دوباره تست کنید.

### راه‌جایگزین (اگر سرویس روی سیستم شما اصلاً بالا نیامد): Task Scheduler

به‌جای سرویس ویندوز، همان برنامه را به‌صورت Task با حساب SYSTEM و استارت خودکار
اجرا می‌کند — نتیجه دقیقاً یکی است و بدون مکانیزم SCM کار می‌کند:

1. **`uninstall_service.bat`** (حذف سرویس ناقص)
2. **`install_task.bat`** را دابل‌کلیک کنید.
3. حذف: **`uninstall_task.bat`**

## تست قبل از نصب (اختیاری)

```bat
:: پاک‌سازی یک‌باره، در CMD با دسترسی ادمین:
RamOptimizerService.exe console --once

:: اجرای دائمی در پیش‌زمینه (مثل خود سرویس، ولی تستی):
RamOptimizerService.exe console
```

---

## روش جایگزین: اجرای مستقیم با پایتون (بدون ساخت exe)

```bat
pip install -r requirements.txt

:: نصب سرویس (CMD با دسترسی ادمین):
python ram_optimizer_service.py --startup auto install
python ram_optimizer_service.py start

:: یا فقط اجرای تستی در پیش‌زمینه:
python ram_optimizer.py
```

## تغییر رفتار برنامه

فقط چند ثابت در بالای فایل `ram_optimizer.py` را عوض کنید و دوباره
`build_exe.bat` را اجرا کنید:

| ثابت | پیش‌فرض | معنی |
|---|---|---|
| `CHECK_INTERVAL_SECONDS` | `60` | فاصله‌ی بررسی وضعیت رم |
| `MEMORY_THRESHOLD_PERCENT` | `75` | آستانه‌ی شروع پاک‌سازی |
| `PURGE_STANDBY_LIST` | `True` | خالی کردن کش حافظه هم انجام شود؟ |

## سؤالات متداول

**آیا امن است؟**
بله — فقط از API های رسمی ویندوز (`EmptyWorkingSet` و همان مکانیزم ابزار رسمی
RAMMap مایکروسافت) استفاده می‌کند. هیچ پروسه‌ای بسته نمی‌شود و هیچ داده‌ای از بین
نمی‌رود.

**آنتی‌ویروس / SmartScreen اعتراض کرد!**
برای exe های بدون امضای دیجیتال ساخته‌شده با PyInstaller این هشدار رایج و
False Positive است. چون exe را خودتان ساخته‌اید منشأ آن مشخص است.

**سرویس را از کجا ببینم؟**
`Win + R` ← `services.msc` ← **RAM Optimizer Service**
